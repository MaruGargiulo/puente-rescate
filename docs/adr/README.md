# Architecture Decision Records

Las decisiones arquitectónicas relevantes se registran acá.

Formato sugerido:

```md
# ADR-XXX · Título

## Context
¿Qué problema o restricción origina la decisión?

## Decision
¿Qué decidimos?

## Alternatives considered
¿Qué otras opciones evaluamos?

## Consequences
¿Qué ganamos, qué sacrificamos y qué deberíamos revisar más adelante?
```

Primeros ADR esperados:
- ADR-001 · Modular monolith para la primera versión.
- ADR-002 · Spring Boot como backend principal.
- ADR-003 · PostgreSQL como sistema de persistencia inicial.
